# Sheng-Skill

A curated collection of skills for AI coding agents. Zero manual steps — the Agent downloads and installs everything automatically.

---

## Skills

### vision-helper — Image Content Analysis

Enables language models without visual capabilities to "see" images by calling external vision APIs and converting image content into text descriptions.

```
Agent Install Directive:
Download all files from https://github.com/azazhsCN/Sheng-Skill/tree/main/skills/vision-helper
to a local skills/vision-helper/ directory,
add its absolute path to your skills config,
install dependencies with pip install -r skills/vision-helper/scripts/requirements.txt,
and copy .env.example to .env prompting the user to fill in their API Key.
```
